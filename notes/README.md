# Selenium Interview Notes Index

This folder is designed to help you study Selenium automation in a practical, interview-ready way. Each topic has a clear explanation of:

- what the concept is
- when to use it
- why it matters in real projects
- how it is implemented in Selenium or Git/Maven

## Recommended learning order

1. Java basics and OOP concepts
2. Selenium locators and waits
3. Basic page interactions (textbox, button, checkbox, radio)
4. Dropdowns, tables, alerts, windows, frames
5. Mouse, keyboard, and advanced actions
6. Shadow DOM, SVG, canvas, and custom widgets
7. Page Object Model and framework design
8. Git workflow, Maven builds, and CI/CD basics

## How to use these notes

- Read each file in order
- Practice the examples on a real application
- Focus on why a technique is used in production, not only how to write the code
- For interviews, prepare answers for: what it is, when it is used, and why it is important

## Interview mindset

A strong Selenium candidate should not only know the syntax, but also understand:

- where the element is located
- what the DOM structure looks like
- which wait strategy is right
- how to debug failures and flaky tests
- how to build reusable automation frameworks
